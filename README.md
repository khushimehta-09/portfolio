# Khushi Mehta Portfolio

A polished professional portfolio website for **Khushi Mehta**, designed with clean layout, modern animations, and recruiter-friendly content.

## Sections
- Hero introduction
- Profile summary
- Education details including 10th, 12th, MBIT CGPA, and certification
- Technical skills
- Featured projects
- Contact section
- Portfolio assistant widget

## Projects
- Voice-to-Voice Translation System
- Secure File Protection System using MFA, encryption, and decryption for real files

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open `index.html` in your browser.
2. Add your profile photo inside the `assets` folder as:
   `profile.jpg`
3. Add your resume inside the `assets` folder as:
   `Khushi_Mehta_Resume.pdf`

## Notes
The contact form is currently demo-only. To make it send emails, connect it to a backend service or form service.
